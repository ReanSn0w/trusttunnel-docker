## Что мы делаем?

Завершаем единый менеджер TLS в Go с тремя явно выбираемыми источниками: Let's Encrypt, генерация самоподписанного сертификата и предоставленная пользователем PEM-пара. Каждый источник обслуживает одновременно VPN и AdminUI. Выполняется первым; не зависит от наличия администратора или VPN-пользователей. В рабочем дереве уже есть непроверенные заготовки `internal/certificate/automatic.go`, `internal/app/automatic_tls.go` и изменения запуска. Они не считаются завершённой реализацией. Имена новых параметров выбора источника предстоит определить; это не уже существующий API конфигурации.

## Для чего мы делаем?

Первый выпуск сейчас требует ручного действия в панели. После неудачного выпуска или остановки endpoint возможны ошибки переходов TLS и публикации. Фоновая работа должна устранять эту зависимость, не блокировать админку и не создавать новый ACME order при каждом рестарте.

  - [ ] Проверить текущий diff без удаления изменений Connection & DPI из предыдущей задачи.
  - [ ] Исправить табуляцию новых environment-полей в `docker-compose.yml`.
  - [ ] Ввести явный выбор ровно одного источника: letsencrypt, self-signed или provided.
  - [ ] Разделить источник сертификата и его операционное состояние в модели persistence.
  - [ ] Сохранить production/staging как параметр Let's Encrypt, а не четвёртый источник.
  - [ ] Определить миграцию существующего manual-сертификата в provided без удаления ключей.
  - [ ] Закрепить `TT_TLS_HOSTNAME` и `TT_ACME_EMAIL` как начальные значения для пустой установки.
  - [ ] Определить приоритет сохранённых настроек над environment при повторном старте.
  - [ ] Добавить понятную диагностику расхождения environment и сохранённого домена без молчаливой замены сертификата.
  - [ ] Валидировать hostname/email только для режима Let's Encrypt.
  - [ ] Валидировать SAN и параметры генерации в режиме self-signed без требования email.
  - [ ] Валидировать пути предоставленной PEM-пары в режиме provided без требования email.
  - [ ] Отклонять конфликтующие параметры разных источников с понятной ошибкой.
  - [ ] Запретить неявное переключение источника при ошибке выпуска или чтения сертификата.

- [ ] Завершить единый фоновый цикл в `internal/certificate`
  - [ ] Запускать первичную проверку сразу после восстановления состояния приложения.
  - [ ] Вызывать первый ACME issue для настроенной установки letsencrypt без сертификата.
  - [ ] Проверять сохранённую PEM-пару на соответствие ключа, домен и срок действия.
  - [ ] Переиспользовать подходящую пару без обращения к ACME.
  - [ ] Рассчитывать окно продления с учётом срока жизни короткоживущих сертификатов.
  - [ ] Ввести ограниченный exponential backoff с jitter после ошибок ACME.
  - [ ] Исключить обращения к ACME в режимах self-signed и provided.
  - [ ] Подхватывать настройки, сохранённые через UI, без рестарта приложения.
  - [ ] Исключить гонку сохранения TLS-настроек с issue/renew/import через общий механизм синхронизации.
  - [ ] Восстанавливать прерванные состояния issuing/renewing без дублирующего выпуска после успешной конкурентной операции.

- [ ] Реализовать постоянный режим self-signed
  - [ ] Генерировать сертификат с SAN общего домена при первом старте без подходящей сохранённой пары.
  - [ ] Хранить сгенерированную пару в постоянном volume с закрытым ключом 0600.
  - [ ] Переиспользовать пару при рестартах без неожиданной смены доверенного сертификата.
  - [ ] Определить управляемую ротацию до истечения срока с явным предупреждением о повторной установке доверия на клиентах.
  - [ ] Предоставлять скачивание только публичного сертификата для установки доверия на телефоне.
  - [ ] Не включать skip_verification при экспорте профиля с самоподписанным сертификатом.

- [ ] Реализовать режим provided
  - [ ] Принимать полную PEM-цепочку и соответствующий приватный ключ через read-only монтирование.
  - [ ] Проверять SAN, срок, формат цепочки и соответствие ключа перед публикацией.
  - [ ] Копировать проверенную пару в единую внутреннюю TLS-ревизию без изменения исходных файлов пользователя.
  - [ ] Подхватывать замену предоставленных файлов в фоне только после успешной проверки полной новой пары.
  - [ ] Сохранять прежнюю действующую ревизию при неполной замене или ошибке чтения исходной пары.
  - [ ] Показывать приближение срока истечения без попытки продлить чужой сертификат через ACME.

- [ ] Завершить интеграцию публикации с endpoint
