Official iOS / Android app limitation

The inspected Flutter client drops Anti-DPI on import. TLS fingerprint and post-quantum settings are not carried by the link format. These controls apply fully to the CLI TOML download; they cannot enable those features in the installed mobile app. Address, transport and IPv6 are imported. A compatible client is required for Anti-DPI.

Blank uses the TLS hostname on port 443. Docker 443:8443 needs external port 443; local smoke uses 127.0.0.1:18443. This does not open ports or change the listener.
Presets fill the form. Save to apply. No preset guarantees access through a particular network.

Disabling this can shrink ClientHello for diagnosis. Conventional TLS and certificate verification remain enabled, but post-quantum protection is lost.

TLS hostname comes from the server certificate. Arbitrary third-party SNI names will not work with this endpoint. TLS random prefixes are admission rules, not a fix for an incomplete ClientHello.
